# raycasting

A basic ray tracer written in Python with NumPy. It renders a scene with two spheres and a plane and saves the result as `raytraced_scene.png`.

Forked from [eraldoribeiro/raycasting](https://github.com/eraldoribeiro/raycasting) (course sample code). My changes: extended `rayTrace.py` into a full ray tracer (camera rays, sphere and plane intersection, shading) and updated the notebook.

## How to Run

```bash
pip install numpy Pillow
python rayTrace.py
```

Or open `rayTracingBasic.ipynb` in Jupyter for the step-by-step version.
